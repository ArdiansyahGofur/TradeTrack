# TradeTrack — Aplikasi Pencatatan dan Analisis Penjualan

TradeTrack merupakan aplikasi berbasis web untuk membantu pedagang mencatat transaksi, mengelola menu, serta memantau pendapatan dan laporan penjualan.

## Teknologi
- PHP Native
- MySQL
- HTML5
- CSS3
- Tailwind CSS
- JavaScript

## Instalasi Lokal

1. Unduh atau klon repository TradeTrack.
2. Letakkan folder project di `C:\laragon\www\tradetrack`.
3. Jalankan Apache dan MySQL melalui Laragon.
4. Buka phpMyAdmin dan buat database bernama `tradetrack`.
5. Pilih database tersebut, lalu buka tab **Import**.
6. Pilih file `database/tradetrack.sql` dan jalankan proses impor.
7. Salin `config/database.example.php` menjadi `config/database.php`.
8. Sesuaikan konfigurasi database dengan lingkungan lokal.
9. Buka `http://localhost/tradetrack` melalui browser.

## Akun Demo

Gunakan akun demo yang disediakan oleh pemilik repository jika tersedia. Jangan menggunakan kredensial akun produksi untuk pengujian.

## Catatan

TradeTrack merupakan proyek portofolio untuk mempraktikkan pengembangan aplikasi web, manajemen basis data, autentikasi, pencatatan transaksi, dan pembuatan laporan penjualan.
